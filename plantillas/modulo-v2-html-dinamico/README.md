# Plantilla visual HTML v2

1. Sustituye los textos y colores en `contenido.html`.
2. Crea los MP3 en `audio/` y añadelos al manifiesto, uno por lámina.
3. Conserva las seis etiquetas `section.slide` y su orden.
4. Comprime el contenido de esta carpeta y cárgalo desde Capacitaciones.

El HTML es visual: el LMS reproduce el audio y habilita el avance solo cuando
termina cada narración. No añadas navegación, reproductores ni llamadas de red.
